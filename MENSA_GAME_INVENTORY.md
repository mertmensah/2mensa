## Missing Core Mensa-Style Games (Priority Order)

1. Analogies and Relationships
- Why: Verbal reasoning benchmark.
- Core loop: A:B :: C:?
- Difficulty levers: abstract semantic links, domain-mixed pairs, timer pressure.

2. Deductive Syllogism Arena
- Why: Strong pure-logic fit with measurable accuracy.
- Core loop: evaluate if conclusion follows from premises.
- Difficulty levers: quantifier traps, nested conditions, negative logic.

3. Numeric Logic Grid (KenKen Variant)
- Why: Bridges arithmetic and constraint solving beyond Sudoku.
- Core loop: fill cages with operations and uniqueness constraints.
- Difficulty levers: grid size, operation complexity, timer constraints.

4. N-Back Memory
- Why: Standard working-memory challenge.
- Core loop: identify repeated items from N steps earlier.
- Difficulty levers: N level, dual-modality (audio + visual), sequence speed.

5. Cryptic Pattern Decoder
- Why: Tests hypothesis formation and abstraction.
- Core loop: decode hidden symbol-to-rule mapping.
- Difficulty levers: number of symbols, rule nesting, partial clues.

6. Optimization Challenge (Shortest Path / Resource Allocation)
- Why: Planning and executive-function style mensa challenge.
- Core loop: achieve best result under constraints.
- Difficulty levers: branching factor, penalties, dynamic constraints.
